# ショートカットの定義（1 行 1 アプリ）
# 書き方:  ファイル名:呼び名 呼び名 呼び名 …
#   ・ファイル（exe やショートカット .lnk）は、この「ショートカット」フォルダに置く
#   ・別の場所にあるアプリは、フルパスで書ける（例 \Storage Card\アプリ\spreadce\AppMain.exe:エクセル）
#   ・呼び名は空白で区切る。英字の大文字・小文字は区別しない
#   ・「〜を開いて」「〜を起動して」のように頼むと、その呼び名のアプリを開く
#   ・# で始まる行は説明（読み飛ばす）
# 例（先頭の # を消すと使える）:
# spreadce.exe:office excel エクセル えくせる 表計算 ひょうけいさん
# \Storage Card\アプリ\ceopener\AppMain.exe:ceopener しーいーおーぷなー
